# Цветочная гостиная

Одностраничный сайт цветочной мастерской с доставкой.

**Сайт:** https://aperevedencev-glitch.github.io/cvetochnaya_gostinaya/

## Что есть на странице

- Проверка доставки: адрес, дата и часовой интервал
- Каталог с фильтрами и тремя размерами букета («Камерный», «Гостиный», «Бальный»)
- Порядок работы: заказ → сборка → фото букета на согласование → вручение
- Калькулятор подписки на цветы
- Памятка по уходу за букетом и частые вопросы
- Корзина с формой заказа (демо: заказ никуда не отправляется)

## Структура

```
index.html   — вся страница: разметка, стили и скрипт
images/      — фотографии букетов
.nojekyll    — отключает обработку Jekyll на GitHub Pages
```

## Как поменять содержимое

- **Букеты и цены** — массив `items` в скрипте внизу `index.html`.
- **Фото букета** — положите файл в `images/` и добавьте путь в объект `PHOTOS` под номером букета (`id`). Букеты без фото показывают рисованную иллюстрацию.
- **Цвета** — переменные в начале блока `<style>` (`--bg`, `--peony` для бирюзовых акцентов, `--coral` для кнопок).
- **Контакты** — в подвале страницы; сейчас там заглушки.

Сборка не нужна: достаточно открыть `index.html` в браузере.
