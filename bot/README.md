# Телеграм-бот «Цветочная гостиная»

Один бот, две роли:

1. **Консультант.** Клиент пишет боту `/start` и получает приветствие и меню: каталог и цены, доставка и оплата, подписка, уход за букетом, гарантия, оформление заказа, контакты. Любое другое сообщение клиента (текст, фото, голосовое) бот пересылает флористу. Флорист нажимает **Ответить (Reply)** на это сообщение, и бот отправляет ответ клиенту.
2. **Уведомлятор.** Форма заказа на сайте отправляет заявку на адрес `/lead`, и бот присылает её флористу в личные сообщения: имя, телефон, букеты, сумма, адрес, дата, интервал и текст открытки.

Бот работает на Cloudflare Workers: бесплатного тарифа хватает с запасом, свой сервер не нужен.

## Как запустить (≈15 минут)

### 1. Создать бота в Телеграме
1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте имя («Цветочная гостиная») и адрес, который заканчивается на `bot`, например `cvetochnaya_gostinaya_bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Никому его не показывайте.

### 2. Создать Worker в Cloudflare
1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) и откройте **Workers & Pages → Create → Create Worker**.
2. Назовите его `flowers-bot` и нажмите **Deploy**.
3. Нажмите **Edit code**, удалите всё и вставьте содержимое файла `worker.js`. Нажмите **Deploy**.
4. Запишите адрес воркера, например `https://flowers-bot.ваше-имя.workers.dev`.

### 3. Задать переменные
В воркере откройте **Settings → Variables and Secrets** и добавьте:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `WEBHOOK_SECRET` | Secret | любая строка из латиницы и цифр, 20+ символов, например `Flowers2026SecretKey88` |
| `SITE_URL` | Text | `https://aperevedencev-glitch.github.io/cvetochnaya_gostinaya/` |
| `ALLOWED_ORIGIN` | Text | `https://aperevedencev-glitch.github.io` |
| `ADMIN_CHAT_ID` | Text | пока пусто, заполните на шаге 5 |

### 4. Подключить бота
Откройте в браузере:
```
https://flowers-bot.ваше-имя.workers.dev/setup?key=ВАШ_WEBHOOK_SECRET
```
Должен появиться ответ с `"ok":true`. Бот подключён, меню команд установлено.

### 5. Узнать свой chat id
1. Найдите бота в Телеграме и напишите ему `/id`.
2. Бот ответит числом. Вставьте его в переменную `ADMIN_CHAT_ID` и нажмите **Deploy**.

Теперь сообщения клиентов и заявки будут приходить вам. Напишите боту `/start`, чтобы увидеть подсказку для флориста, или `/client`, чтобы посмотреть меню глазами клиента.

### 6. Подключить сайт
В `index.html` найдите строку:
```js
const LEAD_URL='';
```
и впишите адрес воркера с `/lead` на конце:
```js
const LEAD_URL='https://flowers-bot.ваше-имя.workers.dev/lead';
```
После сохранения на GitHub форма заказа на сайте начнёт присылать заявки в Телеграм.

## Как поменять тексты
- Контакты — объект `SHOP` в начале `worker.js`.
- Букеты и цены — массив `CATALOG`.
- Ответы на кнопки меню — функция `section()`.

После правок снова нажмите **Deploy** в Cloudflare.

## Защита
- Телеграм присылает вебхук с секретным заголовком: чужие запросы на `/telegram` отклоняются.
- `/lead` принимает заявки только с адреса из `ALLOWED_ORIGIN` и требует телефон.
- В форме есть скрытое поле-ловушка для спам-ботов.
